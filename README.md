# 猫咪养成助手（Bili Cat Butler）

一个**完全开源**的 B 站直播「养猫」活动自动化用户脚本：自动签到、喂食、摸自己的猫、摸同担（排行榜或指定 UID 的猫），可选投喂粉丝手幅。

## ✨ 特性

- 🐱 **「控制台」界面**：深色主题、选项卡布局（猫咪 / 任务 / 日志）、可拖动可折叠
- 🎯 **阶段化任务引擎**：每个房间按「领养 → 签到 → 喂食 → 摸自己 → 摸同担 → 手幅」流水线执行，手幅回馈的猫粮会自动喂掉，逐阶段记录今日完成状态
- 🧠 **智能跳过**：已签到、猫粮耗尽、摸猫次数达上限等返回会被识别并自动跳过，不浪费请求
- 🗂 **任务分组**：不同主播可分配不同动作组合（例如 A 组白嫖、B 组额外投手幅）
- 🔁 **巡航模式**：可设定间隔自动多轮运行，每日已完成的项目自动跳过
- 🚫 **黑名单关键词**：按关键词跳过不想养的房间
- 📦 **选择配置导入 / 导出**：多账号、多套方案轻松切换
- 📊 **今日统计**：成长值、猫粮消耗、摸猫次数实时统计；本地保存每日进度
- 🔒 **零自动关注**：脚本不会修改你的关注列表，不收集个人信息，无远程配置

## 📦 安装

**推荐：从 Greasy Fork 一键安装（自动更新）**

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Edge/Chrome 扩展商店均可搜索安装）
2. 打开 [Greasy Fork 脚本页](https://greasyfork.org/zh-CN/scripts/592922-猫咪养成助手)，点击「安装此脚本」并确认
3. 登录 B 站，打开直播页（`live.bilibili.com`）或动态页（`t.bilibili.com`），左侧会出现「🐈 猫咪养成助手」面板

**手动安装（开发者 / 离线方式）**

1. 打开 Tampermonkey 管理面板 → 「添加新脚本」
2. 删除编辑器默认内容，把 [`bili-cat-butler.user.js`](./bili-cat-butler.user.js) 全部内容粘贴进去，按 `Ctrl+S` 保存
3. 登录 B 站，打开直播页（`live.bilibili.com`）或动态页（`t.bilibili.com`），左侧会出现「🐈 猫咪养成助手」面板

> 也可以把脚本文件放入 Tampermonkey 的「实用工具 → 文件」导入。

## 🚀 使用

1. **准备猫咪列表**：点击「拉取粉丝牌」自动获取你的粉丝牌
2. **选择房间**：搜索 / 筛选后勾选想养的主播（支持「全选本页」）
3. **勾选功能**：签到、喂食、摸自己、摸同担、手幅（手幅会消耗 1 电池，默认关闭；投喂后回馈的 1 猫粮会自动喂掉）
4. **运行**：点击「▶ 开始」

白嫖玩法一般勾选：**签到 + 喂食 + 摸自己**，即可每日获得约 150 成长值。

## ⚙️ 功能说明

| 功能 | 说明 | 默认 |
| --- | --- | --- |
| 签到 | 每日签到领取猫粮 | ✅ 开 |
| 喂食 | 把猫粮喂给猫咪直到耗尽（有安全上限） | ✅ 开 |
| 摸自己 | 摸自己的猫攒满每日 50 成长值 | ✅ 开 |
| 摸同担 | 摸其他用户的猫：摸全部 / 摸前 N 只 / 摸指定 UID（每只次数可调） | ❌ 关 |
| 手幅 | 投喂 1 个粉丝手幅，消耗 1 电池；成功后自动喂食消耗回馈的 1 猫粮 | ❌ 关 |
| 任务分组 | 把房间分配到不同组，每组可单独配置动作开关 | 默认单组 |
| 单次 / 巡航 | 跑一轮，或按间隔循环运行 | 单次 |
| 黑名单 | 关键词匹配的主播会被跳过 | 空 |

## 🔒 隐私与安全

- 所有数据（设置、选择、每日进度、粉丝牌缓存）仅保存在本机 Tampermonkey 存储中
- 仅调用 B 站养猫活动公开接口，不注入页面、不改动关注列表
- 代码完全开源，可自行审计

## 🛠 开发

```bash
npm test           # 完整测试套件：逻辑层 + 引擎层 + UI 层 + 布局层

```

测试覆盖：

- **逻辑层**：设置/迁移、粉丝牌缓存、选择、每日进度、任务分组（新建/重命名/删除/默认组保护/批量分配/重置）、黑名单、统计、接口返回判定
- **引擎层**：完整流水线（领养→签到→喂食→摸自己→摸同担→手幅）、已满即停（成长 0）、指定 UID 预核对、排行榜前 N、登录失效终止、手幅失败处理、手幅成功自动补喂
- **UI 层**：面板构建、登录态、自动拉取、搜索过滤、全选、建组与批量分配、开关联动、重置到默认组
- **布局层**：无头 Chrome 实测面板不溢出、文字不被截断（含 t.bilibili.com 裸标签 CSS 干扰回归）
